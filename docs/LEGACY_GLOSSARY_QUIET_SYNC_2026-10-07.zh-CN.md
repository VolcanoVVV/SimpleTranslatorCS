# 旧译文兼容、安静热同步与可编辑术语表

本轮五个修正版包与 SHA256 均放在 `SimpleTranslatorCS/releases/2026-10-07-legacy-glossary/`，请使用这一目录；根目录旧包保留历史版本内容。可运行 `python tools/package_release.py --output releases/2026-10-07-legacy-glossary` 重现打包。

本轮仍保持 ConfigurationManager.zh-cn **2.13.1**、SimpleTranslatorCS **1.14.0**，遵循 [版本号约定](VERSION_POLICY.zh-CN.md)。更新两边对应 DLL，服务端与客户端均需重启以加载新代码。本轮不替换测试游戏目录中的 DLL、不调用真实付费 API。

## 旧路径直接加载

在 **当前 SimpleTranslatorCS Mod 目录**中，同时支持：

- `db/locales/ch/**/*.json`、`*.jsonc`：旧格式兼容读取，保留原文件，程序不创建旧目录。
- `translations/ch/{MT,API,Manual}`：现行译文路径，新工作台结果只写现行路径。

可将 3.11 示例目录 `zzzzz-simple-translator/db/locales/ch` 的 JSON/JSONC 复制进当前 C# Mod 的同一路径。不要在新服务端同时安装 3.11 的旧 Node/TypeScript Mod；这里兼容旧文件布局，不是为 3.11 提供 C# 服务端 DLL。其他旧目录内的 exe、py、txt 等文件不会作为译文加载，也不会移动。

即使现行路径已有文件，旧路径中新增的译文也会参与下一次启动/管理员重新加载。工作台旧文件标记为 `@legacy/文件名`，与现行同名文件有独立的开关和原文基准。开关/重载仍须有效管理员密钥，玩家不能修改服务器文件。

统一优先级为机器翻译、AI、人工；同层先读旧路径、后读现行路径，现行同层文件覆盖同键。JSONC 的其他稳定排序规则继续保留。人工译文优先于自动结果。旧 `dialogue` 子目录按对话文件读取，工作台标注仍需重启；普通游戏文本重载后发布热同步版本。旧译文与已迁移的重复副本可并存，用户可自行关闭或删除冗余副本。

以前已经迁移到 `translations` 的文件保持原状；历史备份不会自动还原。旧 `workbench` 元数据仍可归类到 cache，已有旧手动开关和基准映射到 `@legacy/`，不会把缓存当译文加载。

## 热同步日志

默认开启 F12 → 服务端汉化 → **隐藏自动同步成功请求日志**。只过滤来自 `RequestHandler`、Info 级别且全文精确匹配的两条日志：

```text
[REQUEST]: /simpletranslator/v1/workbench/live
[REQUEST SUCCESSFUL] /simpletranslator/v1/workbench/live
```

失败、警告、错误、其他接口和其他日志源均保留，全局日志级别不变。关闭选项可恢复这两条调试日志。仍默认每5秒只读检查正式译文版本，不调用 AI、不消耗翻译 token；需要时可调整同步间隔或关闭自动同步。同步结果及失败去重记录继续保存在游戏根目录 `API翻译日志`。

## 术语表位置与编辑

| 场景 | 使用的文件 |
| --- | --- |
| 客户端 F12 AI 翻译 | `BepInEx/plugins/zh-cn/glossary/eft.zh-CN.tsv` |
| 服务端游戏文本 AI 任务（管理员或玩家发起） | 服务端 Mod 的 `glossary/eft.zh-CN.tsv` |
| 复制到 AI 网页的提示词 | 发起客户端的本地术语表 |

发布包只包含 `eft.zh-CN.example.tsv`。首次需要读取时复制为 `eft.zh-CN.tsv`；已有用户文件不覆盖，后续更新示例也不会重置用户配置。F12 AI 页的“打开本地 AI 术语参照表”可定位本地文件。服务端表由运营者编辑，客户端不能通过网络修改。服务器的文件、路径及术语内容不会因此新增公开查询接口。

UTF-8 文本，每行两列，以 **Tab** 分隔；可用文本编辑器或电子表格编辑。原文匹配忽略大小写，带空格的术语还支持下划线及短横线分隔。不同写法分别添加别名；词边界避免 `raid` 误匹配 `raider`。

```tsv
#@enabled=true
#@maxcharacters=800
#@maxentries=24
Ground Zero	中心区
GroundZero	中心区
raid	战局
hideout	藏身处
```

新增/修改行即可调整词条；删除行或在前面加 `#` 即可删除/禁用对应参考。`#@enabled=false` 可停用整表；将内容清空可保留空表，避免删除整个文件后再次从示例初始化。重复原文、缺少 Tab、非法编码及不合法选项会在付费请求前报错，修复后再开始任务。允许最多2000条、256 KiB文件，原文最多80字符、译文最多120字符。

## 成本与稳定性

只匹配本批 **实际原文**，不把整表或所有游戏术语发送给 AI。每批匹配项只放一次，没有新增聊天历史；没有命中时不增加术语提示。默认上限24条、800字符（包括提示头和JSON），允许设置最多64条、2000字符，并且最多占任务输入字符预算的10%；0可禁用。批次切分为相关参考预留预算。字符不等于 token，实际消耗仍以供应商 usage 为准，原有请求次数/输出/已报告token预算继续有效。

两端输入日志会记录每批实际提示词及命中的术语，便于核对译法，不记录凭据。一次任务使用不可变术语快照，修改文件由下一次任务读取，避免中途混用。客户端同会话请求缓存包含对应原文命中的术语；无关词条变化不会重发，有关变化会在主动请求时使用新参考。已经保存且原文未变的译文继续复用，术语变化不会后台付费重翻；如需修正“零号地点”等旧结果，请人工校对，或明确选择重新翻译。术语只作为 AI 参考，不进行危险的全文替换，也不增加自动纠错/校验失败重试；机器翻译 API 沿用原逻辑。

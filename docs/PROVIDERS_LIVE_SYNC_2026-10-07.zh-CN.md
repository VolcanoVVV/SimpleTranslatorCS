# 供应商选择、管理员验证和正式译文热同步

当前旧路径读取、热同步日志及术语表行为以 [本轮补充说明](LEGACY_GLOSSARY_QUIET_SYNC_2026-10-07.zh-CN.md) 为准。

本次版本：SimpleTranslatorCS 1.14.0、ConfigurationManager.zh-cn 2.13.1。

版本号由维护者明确指定，后续修改不自动递增，详见 [版本号约定](VERSION_POLICY.zh-CN.md)。

## 管理员密钥

服务端游戏文本的管理员验证区用文字和颜色共同显示结果：黄色表示未填写或尚未验证，绿色表示服务端确认管理员权限，红色表示密钥无效。浅色主题使用较深的状态字体。填写当前服务器 `workbench-admin.jsonc` 中的 `adminKey`，点击“验证管理员密钥”；AI 平台的 API Key 应填在供应商区域。

更改输入会立即撤销之前的验证状态。填写了管理员密钥却未通过验证时，客户端禁用付费测试和翻译；服务端也拒绝将无效管理员密钥默认为玩家自费投稿。清空管理员密钥后仍可明确使用普通玩家模式。Fika 主机身份或档案身份不会自动获得管理员权限。

本机 4.1 的既有记录显示 API 翻译曾完成，但管理员验证为 `isAdmin=false`，译文进入候选队列。用户已确认更新后仍使用旧管理员密钥。请用当前密钥验证后，在候选审核页检查、批准已有结果即可发布，避免对同一文本再次付费。失败的占位符校验条目需要人工复核。

## 两边共用供应商目录

F12 和服务端游戏文本的 AI 翻译与机器翻译共用 `Shared/TranslationProviderPresets.cs`。供应商按钮展开后可选择预设，并可跳转官方接入文档；F12 原有“AI API”标签统一为“AI 翻译”。服务端另保留“服务端默认”和管理员配置的预设。

- AI：豆包、DeepSeek、Kimi、通义千问、智谱 GLM、Claude、OpenAI、Gemini、Ollama、自定义兼容接口。
- 机器翻译：Microsoft Translator、DeepL、LibreTranslate、百度、有道、Google Translate。

管理员可选择完整目录，为本次任务输入模型 ID、修改接口地址，例如 DeepL Pro 或自建 LibreTranslate；Microsoft 支持本次任务填写资源区域，百度和有道支持应用 ID。切换供应商清空服务端任务的个人凭据，防止把上一家的密钥发送给下一家。客户端设置和服务端任务各自保存参数，F12 个人凭据不会自动转交服务器。

普通玩家可用预设云接口及服务端批准的配置；内置本地、自定义接口仅向管理员开放。玩家不能通过请求正文改写服务端目的地址、供应商或适配器，也不能修改正式译文。服务端 `translation-providers.jsonc` 中的 `enableBuiltinProviders` 默认为 `true`；设为 `false` 可只开放默认及 `aiProfiles`、`machineProfiles` 中的管理员配置。自定义预设 ID 不得以 `builtin:` 开头。

模型列表查询继续保留缓存、筛选、手动输入和关闭自动查询的选项。预设模型 ID 只是初始值；模型是否可用、账户权限、地区和额度由供应商决定。管理员可根据当前账户列表选择新模型；玩家仍受批准模型范围限制。提供模型目录的接口通常不执行生成，查询失败不会自动切换模型或触发付费翻译。

## 热同步的实际范围

服务端正式保存、候选批准、译文修改及重载后发布新的同步版本，并更新当前中文字典。新增覆盖层会在 SPT 4.0 重新构建语言表、4.1 缓存失效时重放，避免运行中生成的译文因后续语言请求而丢失。空的初始译文目录也会注册发现标记及热覆盖，首次生成不必重新启动服务端。

安装配套新版客户端的每个玩家，默认每 5 秒检查 `/simpletranslator/v1/workbench/live`。该接口只读、要求服务端已有玩家档案并受网关限流；请求只携带已同步的版本号，不携带管理员或 API 密钥。版本未改变时不下载译文；候选未批准时不发布新版本。这一过程不调用 AI、不消耗翻译 token，也不受普通玩家手动拉取的 180 秒冷却影响。

客户端在 Unity 主线程合并中文字典、处理撤回并发送刷新事件。合并使用完整的现有字典快照，兼容“合并”及“替换字典”的运行时实现，保留其他游戏和 Mod 文本。英语玩家的英语字典不被覆盖。连接切换后丢弃旧响应；字典未初始化或运行时结构不受支持时延迟重试，不误记同步完成。

F12 中“服务端汉化 / 自动同步正式译文”可关闭同步，间隔可在 2～60 秒设置。成功及错误记录位于游戏根目录 `API翻译日志/ConfigurationManager.zh-cn`，无变化的轮询不写重复日志。服务端原有日志仍位于 `API翻译日志/SimpleTranslatorCS`。

这里的热更新覆盖物品、任务等中文 locale 文本。缓存文字的已打开页面可能需关闭后再打开；商人 dialogue 文件仍按重启提示处理。旧客户端及未安装客户端扩展的玩家无法收到自动刷新。首次升级 DLL 本身需要重新启动相应程序，之后翻译保存无需为每一批重启。

## 构建和安装

五个安装包位于服务端项目 `releases/`，含 SHA256 校验清单。服务端按 4.0、4.1、5.0 BE 分别安装；客户端按 Mono（4.x）或 IL2CPP（5.0 BE）二选一，需已有相应 ConfigurationManager。安装位置沿用上次版本，详见 [模型获取与日志说明](MODEL_DISCOVERY_AND_RELEASE_2026-10-06.zh-CN.md)。安装包不包含管理员密钥、API 凭据、缓存及本机译文。

自动验证包含三种服务端目标各 118 项测试、客户端 262 个回归断言、Mono 4.0/4.1 和 IL2CPP 构建、IL2CPP API 冒烟及布局边界检查。测试使用临时文件和本地模拟供应商，没有使用用户密钥消费 token。另已只读核对本机 IL2CPP 字典枚举 API。尚未进行真实 Fika 多客户端联机画面验收，不能保证所有第三方 UI 缓存都响应刷新事件。

后续添加供应商应修改共享目录并同步两份文件及 `Shared/manifest.json`，通过 `tools/Verify-Foundation.ps1`；新增非兼容协议还需增加适配器和模拟请求测试。同步协议以 `provider-catalog`、`live-sync` 能力协商，旧服务端继续保留手动拉取路径。

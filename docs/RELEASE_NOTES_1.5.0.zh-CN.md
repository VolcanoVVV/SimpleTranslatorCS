# SimpleTranslatorCS 1.5.0

本版提供 SPT 4.0、4.1 和 5.0 BE 三个安装包。按实际服务端版本选择，解压到包含 `user/mods` 的服务端根目录后重启。5.0 BE 包针对此次构建使用的测试版运行时。

## 相比公开版 1.4.1

- 支持独立网页直接连接 SPT，拉取原文、编辑并发布译文。只管理服务端时无需运行游戏。[F12 与独立网页工作台 2.14.1](https://github.com/VolcanoVVV/ConfigurationManager.zh-cn/releases/tag/2.14.1)
- Fika 和远程管理需要管理员授权。远程连接使用受信任的 HTTPS。玩家投稿经管理员审核后发布。
- 发布会校验目录修订号和条目原文。网页 AI 译文按当批来源可合并为 `来源A.来源B_API.jsonc`。旧版分层目录和 `db/locales/ch` 仍可原位读取。
- 新版客户端按通知拉取译文增量。空闲时无需循环请求 `/workbench/live`。

升级前备份译文、配置和术语表。初次使用 API 建议先试译少量条目。已送达供应商的请求在取消或超时后仍可能计费。
